organization, administrator, UOR-specific account or unique display name.

scoped redundant ownership, quorum, durable replay/rollback defenses and
cross-organization isolation remain required. Existing mail infrastructure is
an interoperability boundary, not authority over Foundry account logic.

The default target remains `https://uor-foundation.github.io/foundry-web/`.
No DNS or custom-domain change is implied. GitHub Pages supplies bootstrap
assets; participant/faculty browsers execute the modeled service. Public peer
operators are permitted, but connectivity and replication must be observed.

`hologram-live` is authoritative for `.holo`. Integrity, signature validity,
upstream format compatibility, producer readiness and live product acceptance
are distinct checks. No one of them substitutes for the others.

The complete `just vv` gate and all required deployment checks remain mandatory.
First-party crates.io publication follows actual Foundry deployment acceptance.
